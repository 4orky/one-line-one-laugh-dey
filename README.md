Twelve original one-line jokes go in; the program scores each one against the judge's five criteria, keeps the strongest, and writes it to `/output/entry.txt`. The winner:

> My smoke alarm only goes off when I cook. I have decided it believes in me.

Run it with `python3 main.py` — no arguments, no network, no setup.
